# FAQ

## Czy dane w API są cachowane?

Nie, dane o terminach i lekarzach zwracane są w czasie rzeczywistym z uwzględnieniem wszystkich zmian i nowych wizyt.

## Czy można zlecić oprogramowanie indywidualnego widżetu rejestracji w Medfile?

Tak, nasz zespół jest gotowy na przygotowanie indywidualnego widżetu rejestracji na zamówienie w technologiach takich jak VueJs lub ReactJS na podstawie ustalonego projektu graficznego i specyfikacji dostarczonej przez klienta.

## Ile czasu można testować rozwiązanie za darmo?

Testowanie API możliwe jest przez 90 dni za darmo.

## Nie chcę używać formularza Medfile do umawiania wizyt pacjentów, jakie są inne możliwości?

Jeżeli chcą Państwo samodzielnie zapisać pacjenta do kalendarza proszę skorzystać z dokumentacji: [Rejestrowanie wizyt przez REST API](./Rejestrowanie-wizyt-przez-api.md)

## Chcę nie tylko umówić wizytę, ale też mieć możliwość przeniesienia lub anulowania wizyty pacjenta.

Ten interfejs nie umożliwia takiej integracji. Aby mieć możliwość zarządzania kalendarzem oraz pacjentami mogą Państwo skorzystać z naszego dodatkowego interfejsu Medfile API (FHIR).
