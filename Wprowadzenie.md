# Wstęp

Dla klientów budujących własny interfejs do rejestracji pacjentów stworzyliśmy dedykowany interfejs REST API o nazwie Medfile Widget API tzw. API do rejestracji online. Usługa umożliwia wyszukanie m.in. specjalisty, usługi oraz terminu. Następnie dedykowany endpoint umożliwia finalizację rejestracji bez wychodzenia z Państwa aplikacji.

## Podstawowe informacje

- Adres API: https://wapi.medfile.pl 
- Interaktywna dokumentacja: https://wapi.medfile.pl/docs 
- Testowy token: **DemoToken**

## Przypadki użycia

- Gdy klient chciałby pokazać na swojej stronie listę specjalistów, którzy pracują w jego placówce i wolne terminy.
- Gdy klient chciałby zaprojektować swój własny widżet wyszukiwania lekarza i wolnego terminu.
- Gdy klient chciałby zbudować swojego ChatBota lub asystenta AI i potrzebuje informacji o lekarzach i terminach.
- Gdy klient chciałby w jednym API mieć informacje o lekarzach i terminach z wielu różnych kont w aplikacji Medfile.

## Jak uzyskać dostęp do produkcyjnego API?

Proszę wysłać wniosek na adres integracja@medfile.pl.
We wniosku proszę wskazać których kont ma dotyczyć token. Następnie nasz zespół zweryfikuje Państwa wniosek i skontaktuje się w celu ustalenia szczegółów.

Po rozpatrzeniu wniosku i aktywacji usługi otrzymają Państwo dedykowany token.
